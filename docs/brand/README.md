# MAMÁ brand files

Ready-to-share exports of the Mamá logo. The app's own launcher icon and `MamaMark` live under `app/src/main/res/` and are not built from these files.

| File | What it is | Use |
| --- | --- | --- |
| `mama-logo-cuadrado.png` | 1024 px, full-bleed chartreuse | App icon, store listing |
| `mama-logo-redondo.png` | 1024 px, round, transparent corners | Profile pictures |
| `mama-lockup-claro.png` | Logo + "MAMÁ" + slogan on paper `#FBFBF2`, 3200×1600 | Slides, light backgrounds |
| `mama-lockup-oscuro.png` | Same on charcoal `#181918` | Slides, dark backgrounds |
| `mama-ilustracion.png` | The original riso illustration with its circle | Print, pitch |
| `mama-ilustracion-sin-fondo.png` | The illustration on a transparent background | Stickers, compositions |

Slogan: "Mamá, siempre en el momento correcto". Palette: charcoal `#181918`, chartreuse `#EFFE00`, paper `#FBFBF2`, olive `#4A5400`. Wordmark font: Lexend 700.
