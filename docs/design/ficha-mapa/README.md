# Route map screenshots (#143, part 1)

Taken locally with the simulated walk and the still case, at 1280x800 and 390x844.

- "antes" is the drawing alone, as on main. Today it is also the fallback: no
  `CARTO_BASEMAPS_KEY`, or tiles that cannot load.
- "después" shows the map. These shots were taken without a CARTO key, so the
  basemap tiles are Esri's gray canvas standing in for CARTO's dark_all and
  light_all. Everything drawn over the tiles is the real page: the route, the
  dots, the accuracy circle, the controls and the attribution.
