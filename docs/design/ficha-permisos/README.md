# Phone permissions screenshots (#125, part 2)

Taken locally on two seeded cases (widget alerts, so no call), with no
CARTO key: the route is the drawing alone.

- "verde": only the microphone is off, which is not important, so the node
  is green with "8 de 9 ✓".
- "amarillo": the battery is restricted, so the node is yellow and the list
  says what is missing. Background location was lost and then granted again
  after setup, so the central strip and the PDF show two marked changes.
- `-inicio`: on a phone the track scrolls to the step the case waits for;
  these shots scroll it back to the first node.
- `-chips`: the list open (a popover).
- `central-*`: the strip under the track, in the dark and light themes and
  at phone width.
- `pdf-*`: the draft PDF's two pages.
