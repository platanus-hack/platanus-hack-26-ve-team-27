# La alarma de la frase (#143)

Capturas de un servidor local de la rama `ticket/alarma-frase` con casos de prueba (datos inventados), tema oscuro, en el orden en que pasa un caso. La alarma es un chip al lado del nombre:

| Momento | Archivos |
| --- | --- |
| Twilio oye la frase (chip rojo latiendo, marco fino) | `frase-*` |
| El veredicto la confirma | `confirmada-*` |
| Sellado (chip rojo quieto) | `sellada-*` |
| La lista de la central | `lista-1440-oscuro.png` |
| Se oyó en vivo pero el veredicto dice sin coacción | `pasoatras-ficha-1440-oscuro.png` |

Las capturas de 390 son de página completa: el marco es fijo a la pantalla, por eso solo cubre la primera pantalla.
